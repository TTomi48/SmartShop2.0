## AD-05 – Opcionális Cloudflare Tunnel Dockerben

- **Dátum:** 2026-11-12
- **Fázis:** üzemeltetési konfiguráció és ellenőrzés
- **Eszköz:** Codex; a pontos modellazonosító nem áll rendelkezésre.
- **Kapcsolódó követelmény:** EF8 adatmegőrzés; az üzleti szabályok és az adatbázis-konfiguráció nem változtak.

**Felhasználói kérés:** „hozzuk létre egy cloudflare tunnel-t a dockerben és az envbe írom bele majd az id-t”. Kontextus: `compose.yaml`, `.env.example`, nginx-konfiguráció, Dockerfile, API-kliens és specifikáció.

**AI-javaslat és megvalósítás:** külön `compose.tunnel.yaml` kiegészítés, amely a `cloudflare/cloudflared` konténert a meglévő Docker-hálózatra kapcsolja. A connector a `CLOUDFLARE_TUNNEL_TOKEN` változóból kapja a tokent. A Cloudflare-ben beállítandó cél `http://frontend:80`; az nginx már kezeli az `/api/` továbbítását. A helyi indításhoz továbbra sem kell token. A token és a tunnel ID közti különbséget a [Cloudflare dokumentációja](https://developers.cloudflare.com/tunnel/reference/tunnel-tokens/) alapján ellenőrizte az asszisztens.

**Felhasználói döntés:** a Dockerben futó tunnel és az `.env` használata kifejezett kérés volt. A külön Compose-fájl az asszisztens megvalósítási döntése; külön felhasználói értékelés erről még nem történt.

**Futtatási bizonyíték:** Docker Compose v2.40.3 alatt, ideiglenes környezeti fájllal és tesztértékekkel végzett ellenőrzések eredménye:

```text
PASS: local configuration without tunnel token
PASS: missing token rejected
PASS: empty token rejected
PASS: token mapping, startup command, healthy frontend dependency and no published tunnel ports
```

Az ellenőrzés a `docker compose config --quiet` és `config --format json` parancsokat használta az alapkonfigurációra, illetve a két Compose-fájl együttesére. A JSON feldolgozásával ellenőrizte a token átadását, az indítóparancsot, a frontend egészséges állapotára várást és a publikált tunnelportok hiányát. Valódi titok nem került a kimenetbe. A `git diff --check` szintén sikeres volt.

**Korlát:** élő tunnelkapcsolat, publikus hostname és azon keresztüli API-elérés nem lett ellenőrizve; ezekhez a felhasználó tokenje és Cloudflare-beállításai szükségesek. Alkalmazáskód nem változott, frontend- és backendtesztek nem futottak. A reprodukálható indítási és kézi ellenőrzési lépéseket a README Cloudflare Tunnel része tartalmazza.
